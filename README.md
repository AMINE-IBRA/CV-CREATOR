# CV Creator

A modern, user-friendly CV builder built with React and Vite.

## Overview

CV Creator helps users create professional resumes quickly and efficiently. The interface allows users to enter their personal details, work experience, education, skills, and more, then preview the results in real time.

## Key Features

- Clean, responsive React interface
- Live CV preview while editing
- Easy form-based entry for profile details, experience, education, and skills
- Export-ready layout for a polished final resume
- Fast Vite-powered development and build workflow

## Project Structure

- `src/` — React components and styling
- `public/` — Static assets and icons
- `package.json` — Project dependencies and scripts
- `vite.config.js` — Vite configuration

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Notes

This project is designed as a polished resume creator for small businesses, freelancers, and professionals seeking a simple, effective way to prepare CVs.
